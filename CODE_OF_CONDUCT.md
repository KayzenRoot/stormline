# Code of Conduct

Stormline is a public, owner-operated engineering project. Its engineering governance does **not** require external reviewers. Public interaction should remain professional and constructive.

## Expectations
- Discuss software, evidence, security and design choices respectfully.
- Provide reproducible data instead of personal attacks or harassment.
- Respect intellectual property, attribution, access controls and confidentiality.
- Avoid discrimination, threats, targeted harassment, spam, disclosure of private information and malicious submissions.

## Enforcement
The repository owner may moderate public issues, comments and contributions, including closing threads or restricting participation where GitHub permissions allow. No external moderation committee or reviewer is required.

For confidential security matters, follow [SECURITY.md](SECURITY.md); **never post exploit details publicly**. Enforcement decisions are limited to the repository and the GitHub platform’s policies. This policy does not impose a review SLA or guarantee acceptance of outside contributions.

# Support

Stormline is a research and development initiative, not a released end-user game engine. **No downloads, binaries, editor, SDK, documentation for a public API, or formal end-user support channel currently exist.**

- For project intent: [README](README.md) and [overview](docs/01-project-overview.md).
- For verified project status: [checkpoint](docs/11-checkpoint.md).
- For decisions: [Decisions Ledger](docs/10-decisions-ledger.md).
- For non-security issues: [issue templates](.github/ISSUE_TEMPLATE) (responses and adoption are not guaranteed).
- For confidential security reports: [SECURITY.md](SECURITY.md).

Please avoid posting personal information, credentials or licensed third-party assets in public issues. No paid support or externally staffed review team is associated with Stormline.

# ADR-0028 — Coarse Cells, Exact Interest Receipts and Budgeted Asynchronous World Streaming

**Status: PROPOSED / NOT APPROVED FOR ENGINE CODE**  
**Date 2026-11-14 | Research #165 | NLE-P00-WO-002-WORLD-03 | Future code #43 OPEN/BLOCKED.**

## Context
The planned Stormline world needs traverse-large-area streaming without main-thread stalls above approved thresholds. Streaming, physics/network authority, spatial proximity, rendering, source scenes and disk/asset caches have different owners. A camera-only loading policy risks deleting physics-critical colliders; a single dynamic index for all 2D/3D/NET/GPU uses risks incorrect visibility and ownership. Large coordinate origin shifts can cause world/physics/camera desync. Runtime code, target hardware and budgets are not currently approved.

## Decision PROPOSED
1. **Two logical indexes, not one magical global tree:** coarse sparse spatial cell partition for residency source IDs with 2D/3D policy; optional per-active-cell loose AABB/BVH/R-tree for CPU interest candidates. Exact query must refine bounds and surface `INCOMPLETE` for nonresident cells. R-tree Boost BSL-1.0 and libspatialindex >=1.8 MIT alternatives are **not adopted** without native/Web benchmark/rights gate. PHYS broadphase and GFX-04 culling remain other owners.
2. **Global stable cell coordinates and instance identity** survive render-origin relocation; checked negative grid floor division, world/asset source and EntityGuid generation. One canonical owner per overlapping object and deduplicated cross-cell proxies; no duplicate ECS entities spawned by broadphase.
3. **Authority-scoped interest union and residency policy:** server/physics/AI/player/camera/audio/editor propose bounded areas with distinct role; required simulation assets pinned, speculative cells lower priority. NET controls replication visibility/authority and cannot be overridden by remote client or MCP. Predictive lookahead, enter/exit hysteresis, cooldown and bounded prefetch reduce thrash but **do not guarantee no stalls**.
4. **Explicit lifecycle from request to ACTIVE and safe EVICT:** DATA-05 owns asset I/O/decode/caching, CORE owns scheduling, WORLD-02 owns source scenes, WORLD-01 runtime entities. WORLD-03 returns versioned TaskGeneration/WorldEpoch/CellGeneration receipts, stages data, checks hashes/source revision/rights and submits safe tick-barrier commit intents to owner. GPU resources GFX-03 and physics colliders PHYS require separate ACK/fences; no partially visible active cell or stale callback resurrection.
5. **Bounded budgets/backpressure/fault handling:** quotas for CPU plan/decompression staging/I/O bytes/pending tasks/GPU VRAM leases/physics shape insertion, no eviction until every live pin/lease/fence released, cancellation/backoff under teleport/device loss, previous coherent snapshot or safe loading gate on misses. Unknown memory = UNKNOWN not a fabricated success. Deduced “async” does not mean no main-thread blocking.
6. **Coordinated global-to-local origin:** CORE-05/PHYS/GFX/NET define authority/precision/epoch and shift ACK; WORLD-03 can request shift but cannot unilaterally rebase simulation or network, never reassign stable world cell IDs or EntityGuid when origin shifts. In split-screen multiple view origins may differ.
7. **Separate render/simulation interest and quality:** 2D tile and 2.5D artist scenes stay authored, mesh/HLOD/terrain GFX-04/WORLD-04, DATA-05 cache and cooker; do not silently remove collision/AI state to improve GPU p99. Headless can stream gameplay-critical data without GPU.
8. **Secure Editor/CLI/MCP contracts:** read-only bounded interest/cell diagnostics and staged, audited policy transactions through DATA-04 CAS; no cross-world/project queries, arbitrary remote fetch, file paths, untrusted asset code or malicious infinite cell pins. Pin/scheduler APIs use owner capability.
9. **SIP Stormline Interest Predictor optional PROVE-OR-DROP**, compare simple velocity lookahead+priority baseline; cannot weaken sim completeness or permissions.
10. **Do not activate code by documentation:** future #43 OPEN/BLOCKED, ADR-0028 PROPOSED, all 80 coding WOs `BLOCKED_PENDING_TECHNOLOGY_AND_CONTRACTS` / `executor_ready=false` / approved_adr=null and release class UNDECIDED. Mandatory WORLD-02/DATA-05 code not built; CORE-04 research gap remains.

## Rejected unconditional defaults
Always load nearest camera only; unload as soon as camera crosses radius; presume an async read implies no main-thread stalls; replicate all cells to clients; serialize float-relative origin as permanent position; share scene physics collision broadphase as a mutable render/stream index; ignore cancellation after world unload; evict pinned required collision on GPU memory pressure; assume WebGPU/SharedArrayBuffer in WebGL2 browser; copy Unreal/Unity proprietary code; declare high performance based on marketing screenshots.

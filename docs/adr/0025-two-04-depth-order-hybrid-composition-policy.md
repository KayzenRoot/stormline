# ADR-0025 — Depth-Explicit Hybrid 2D/3D Composition and Coherent Lighting

**Status: PROPOSED / NOT APPROVED FOR ENGINE CODE**  
**Research #156 | WO NLE-P00-WO-002-TWO-04 | Future code #40 OPEN/BLOCKED** | 2026-11-14.

## Context
The Stormline catalog targets orthographic/perspective hybrid scenes with sprites and 3D world preserving ordering/lighting. A single layer/Y sort is insufficient for per-fragment mutual occlusion. Conversely, forcing all Canvas/UI into 3D world depth breaks artist-ordered overlays and pixel-art sharpness. Offscreen viewports can isolate one camera but their color output does not automatically carry compatible depth into another camera. Transparent overlapping geometry, scene-linear HDR, shader output and device memory create competing constraints. Actual performance/hardware compatibility is untested.

## Proposed decision
1. **Three explicit mutually distinct modes:** `SHARED_DEPTH_WORLD` for in-world sprite/mesh per-pixel depth testing, `ORDERED_CANVAS_OVERLAY` for stable Canvas painter/HUD layers, `ISOLATED_SUBVIEW` for render-to-texture with depth-loss stated unless an explicit verified compatible reprojection exists. Invalid mode combinations fail with typed warning; never silently flatten author-intended occlusion.
2. **Ownership:** TWO-04 generates versioned composition/depth-layer/anchor pass intents, never a second Canvas renderer, GPU compiler/allocator, 3D mesh renderer, material light solver or tone mapper. TWO-01, GFX-01..08 and DATA/PHYS/WORLD remain authoritative.
3. **Projection & units are explicit:** orthographic/perspective GFX-07 camera, source DATA-03 glTF axis/units import, checked 2D logical px ↔ local 3D meters ↔ camera clip/depth and rebasing. Billboard facing and pivot, sprites on world planes, constrained Y/baseline sorts, masked and blend depth-write rules are first-class choices.
4. **Hybrid depth truth:** GFX-03 owns compatible depth/stencil attachments and hazards, GFX-04 3D meshes/culling, GFX-05 color/premultiplied alpha/PBR, GFX-06 2D/3D lights/shadow/volumetric, GFX-07 HDR/AA/post and temporal flags. Shared-depth uses common projection/linear depth or a formally valid transform, not fake screen-space alignment.
5. **Transparency cannot be “solved” by a single global sort:** stable painter order for Canvas, masked sprite writes depth as applicable, blended world sprites generally depth-test without depth-write, with declared group/priority policy and known intersection limits. Weighted blended OIT optional approximate, not exact refraction/deep overlap. PPLL/FBO heavy techniques not mandatory WebGL2.
6. **Lighting and color are requested, not duplicated:** optional lit billboards with GFX-06 normal/shadow proxies, unlit baseline and bounded per-sprite receiver masks. Compose in linear HDR before proper GFX-07 output transform where compatible; native-res unjittered UI after relevant scene post, preserving accessibility contrast.
7. **Web/native device tiers and budgets:** WebGL2 baseline no compute, WebGPU feature-probe depth/stencil/attachment and backend capabilities, Metal/Vulkan/DX12 adapters separately test. GFX-03 versioned attachments/fences; subview recursion/pixel/VRAM, extra passes, GPU alpha overdraw and p50/p95/p99 budgets unproven. Feature fallback must be truthfully labeled without incorrect occlusion.
8. **AI-native editor safe scene transactions** with DATA-04 version/CAS, bounded camera/layer/anchor/subview settings and ACL; read-only inspection does not fake rendered screenshots. No arbitrary import/shader/script/file access or cross-project viewport.
9. **SDOI** (Stormline Depth–Order Integrity Inspector) optional PROVE-OR-DROP against simple depth/mode validation; no novelty, correctness or speed proven.
10. **Code remains blocked:** release class and numeric DoD undecided, TWO-01/GFX-04 implementations absent, source ABI/shader files/platform/hardware/golden scenes and attachment compatibility not frozen. All 80 coding WOs `BLOCKED_PENDING_TECHNOLOGY_AND_CONTRACTS` and executor_ready=false, #40 OPEN/BLOCKED; ADR-0025 PROPOSED, no automatic owner approval.

## Rejected defaults
Everything rendered in one painter sort regardless of world depth; every sprite forced into 3D opaque depth regardless of alpha/UI; subviewport color treated as compatible 3D depth; Godot/Unity proprietary or open source code/asset copied without integration rights; WebGL2 PPLL/compute assumed available; average 60 FPS assumed without actual measurements; every 2D sprite casts a 3D shadow; viewport memory unlimited.

# ADR-0031 — Engine-Owned 2D Physics API, Fixed-Tick Authority and Replaceable Solver

**Status: PROPOSED / NOT APPROVED FOR CODE**  
**Date:** 2026-11-14 | SIM-01 research issue #174 | WO NLE-P00-WO-002-SIM-01 | Coding #46 OPEN/BLOCKED.

## Context
Stormline requires original physics 2D integrated with ECS, Canvas and tilemaps in native/Web/headless. A low-level solver binding leaked into public engine API would compromise data ownership, tests and future replacement. Rendering timestamps must not drive physics. Collision callbacks can mutate/destroy entities during a step and break determinism. Box2D 3.x is modern MIT C17 backend, but comparison with Chipmunk/Rapier and exact platform/precision proof remains to be made.

## PROPOSED decision
1. **Stormline-owned semantic façade** for PhysicsWorld2D, generational Body/Shape/Joint refs, qualified ECS World+EntityGuid, immutable source config and event batches; no Box2D/Rapier/Chipmunk public types, raw pointers or private callback ABI. Multiple physics worlds isolated by WorldInstanceEpoch and owner.
2. **Box2D 3.x MIT C17 as LEADING CANDIDATE not adopted**. Compare Chipmunk2D C99 MIT and Rapier2D Rust Apache-2.0/FFI+WASM on correctness/ABI, memory, build, deterministic event/replay and native/Web p95/p99. Choose release+license pinned only after approved runtime constraints and bench. Not writing a bespoke 2D solver until evidence warrants risk.
3. **CORE-06 fixed tick is sole simulation clock**. Candidate dt 1/60 s, substeps 4 reference, explicitly TBD owner numbers. Simulation commands validated and queued at pre-step barrier, contact/sensor events consumed after step and serialized deterministically under replay profile, render interpolation read-only in TWO-01. No mutation inside solver callbacks; GAME/NET uses next tick commands. World origin/scale conversion via CORE-05 and physics origin epoch, not Canvas pixel density.
4. **Stable state/handle lifecycle**: Body/Shape/Joint `{world,slot,generation}` and ECS EntityGuid separate, stale events/callback data checked, destroying/reparenting/teleport/filter change at safe barrier only, collision presence/PHYS ACK across WORLD-03/TWO-02 cell readiness. Dynamic source transforms physics-authoritative; static authored revisions and kinematic targets source-owned.
5. **Shapes/filter/event semantics**: circles/capsules/boxes/convex polygon, static chain edges with ghost vertices from cooked TWO-02, multiple shapes, mask+category/group, solid vs sensor, bounded ray/overlap/shape cast, contact begin/end/hit and sensor begin/end after step with generation-checked references. Chain winding/corner snagging, opt-in event cost and CCD tunneling limitations explicitly tested. Joint matrix by actual pinned backend; no fluid/soft body/advanced 3D in SIM-01.
6. **Headless and portability**: no GPU/editor dependency, C17 Box2D candidate via private adapter, Web/WASM support proven by real build, Win/Linux/macOS platform and compiler/precision/SIMD pinned. Box2D docs 3.1+ cross-platform deterministic claim is a **hypothesis to confirm at Stormline layer** by byte-replay golden of exact same input/world config, tick command order and engine-owned event receipts; snapshot/rollback requires complete backend state and separate NET policy. No unconditional peer sync/authoritative physics claim.
7. **Safety/resource quotas**: reject nonfinite/out-of-bounds positions and force, oversized imported polygons/chain, invalid constraints/winding and malicious event/query floods, cross-project/world references. All physics source mutations DATA-04 journal CAS, DATA-03 asset import validation, source collision rights, safe retirement and stage failure receipt. Fail closed on insufficient memory/critical collider readiness rather than silently remove ground or exceed catch-up budget.
8. **Evidence requirements**: future collisions at rest, thin fast bullets, sensor fast movements, towers/joints/sleeping, tile chain ghost edges, replay across 1/2/8 workers and OS/WASM, broadphase oracle, ECS lifecycle, GFX visualization independence, world streaming collider ACK, malformed graph/shape fuzz, headless p50/p95/p99/memory. Explicit numeric target and no HIGH/CRITICAL before coding/deploy.
9. **Owner gates**: WORLD-01+TWO-01 coding deps not implemented, CORE/DATA/WORLD owners only research proposals, Scope/1.0 DoD and backend not approved. All 80 implementation WOs blocked/executor_ready=false, future #46 OPEN; historical CORE-04 research gap pending. This ADR is **PROPOSED**, not owner-approved.

## Rejected defaults
Public solver API types in engine code; solver directly mutates ECS during callback; physics driven by variable render dt; pixel coordinates treated as meters; physical contacts reused as streaming or visual culling; rigid-body movement from visual interpolation; force global transform to physics without checked parent+scale; assume CCD guarantees all trigger events; universal deterministic claim based on vendor FAQ; checkpoint/registry software unlock from documentation alone; copy competitor visual sample assets.

## Future proof obligations (none executed)
Accepted ABI/units/time contract and approved backend tag, physics 2D native/Web/headless builds, real stress/CCD/chain/filters/joints/movement tests, replay/rollback with independent golden state hashing, event ordering/stale handles, crash/cancel, resource limits, collision source provenance and p95/p99 hardware budgets. Numeric budgets and release class currently UNDECIDED.

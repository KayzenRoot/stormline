# ADR-0029 — Source-Authored Terrain Patches and Explicit Environment Ownership

**Status: PROPOSED / NOT APPROVED FOR CODE**  
**Date:** 2026-11-14 | Research #168 | WO NLE-P00-WO-002-WORLD-04 | Future coding #44 OPEN/BLOCKED.

## Context
Stormline aims at original editable multi-biome 3D worlds, including terrain sculpt/splat, foliage, coast and water, sky/weather/day/night. Rendering, scene source, streaming, physical collision, simulation/game weather and visual particles already have distinct owner modules. A “terrain renderer” inside WORLD-04 risks duplicating GFX-04, GFX-05, GFX-06 and WORLD-03; naive editing could overwrite artist source, leave seams or desync PHYS; magical real-time volumetrics/mesh shader support is not portable to WebGL2. No dependent engine is built.

## PROPOSED Decisions
1. **WORLD-04 owns authored terrain and environment semantic data**, stable global patch source IDs, local edit-layer provenance, biome/vegetation authored placement and water/sky profile assets/typed visual intent. DATA-04 owns persistence, CAS journal/undo/redo, DATA-03/05 own import and cook/stream. **WORLD-05** owns procedural biome/erosion/worldgen algorithms and seeds. WORLD-04 never creates a second core scene/asset database.
2. **Terrain source is a typed heightfield patch scheme with a distinct mesh topology path** for holes, arches, caves, vertical cliffs and overhangs. Never promise a heightfield can model arbitrary 3D topology; geometry and HLOD belong GFX-04. Patch IDs and border sample convention independent from camera origin, single source basis for visual and PHYS collision revision handshake.
3. **Terrain LOD chosen after benchmark**: portable tile/quadtree stitched+skirt+geomorph reference baseline vs GPU geometry clipmaps optional, hardware mesh shader/tessellation as opt-in after feature probes. GFX-04/GFX-03 and GFX-02 own final geometry pipeline and GPU memory. Quantify crack/normal error, origin jitter, visual silhouette, memory and p95/p99, not only draw calls.
4. **Normalized material weight source** and slope/biome masks belong authored terrain; GFX-05 owns PBR, texture arrays/virtual residency and linear-space blending. No second BRDF/splat shader system owned WORLD-04, no imported material packs without provenance.
5. **Foliage grouping/placement source** (manual edit layers, stable instances) and biome palette belong WORLD-04, procedural spawns belong WORLD-05, final batching/visibility GFX-04, shadows GFX-06 and weather particles GFX-08. GPU sway is cosmetic; gameplay wind and collider/nav truth belong GAME/PHYS.
6. **Water surface is visual first** with limited-tier Gerstner/baked waves, authored bodies and shore masks. Spectral FFT/planar reflections/cloud volumes optional only after GPU capability+cost proof; PHYS owns buoyancy/flow and GAME/NET own wetness or climate authority, not a water shader result. Reflect/refraction/SSR limitations explicit with GFX-05/07.
7. **Atmosphere/weather source versus rendering truth:** EnvironmentProfile and WeatherVisualIntent are scene-authored parameters, physical sky/irradiance/fog and light GFX-06, HDR/post/color GFX-07, particles GFX-08, authoritative weather/time CORE/GAME/NET. Portable analytic sky fallback, Bruneton BSD precomputed sky optional GFX owner with license and cross-platform gates.
8. **Non-destructive semantic editing:** Stage→Preview impacted patches/neighbors/PHYS/GFX/Data05 recook→Validate rights/source revision/sizes→DATA-04 journal CAS→WORLD-03 safe staged publish→OWNER ACKs→report consistency with typed error; undo and changed base honor manually authored overlays. Editor/CLI/MCP parity with no arbitrary shader/native code/filesystem/URL access.
9. **SABE optional PROVE-OR-DROP** adaptive biome visual error budget vs simple independent LOD; never disable required PHYS collision/authoritative pins for FPS. No claim novel/faster without reproducible original-scene visual+performance evidence.
10. **No runtime authorization**: WORLD-03 and GFX-04 coding prerequisites not implemented, ADR-0029 remains PROPOSED, 80 implementation WOs BLOCKED/executor_ready=false, release class UNDECIDED and approved_adr=null, future #44 OPEN. Historical CORE-04 research gap remains pending. Need owner 1.0 Scope/DoD and independent build/test/benchmark/safety approvals.

## Rejected unconditional defaults
Only a heightmap for all caves and overhangs; terrain LOD generated directly into GPU without PHYS source/collision reconciliation; normal-map/splat gamma math hacked in WORLD-04; arbitrary procedural generators overwriting artist strokes; rendering fog and post inside WORLD-04; physically accurate water implied by wave shader; full raytraced volumetric weather required on browser; compute/mesh shader mandatory; unlicensed Unreal sample landscapes/asset packs; superiority based on old published benchmarks.

## Future NOT EXECUTED proof obligations
Signed/stable source IDs, seamless patch boundaries and morph/collision reference, undo/rebase/recook, caves separate mesh, foliage instance/LOD/shadow alpha, coastal wave/refraction and authoritative PHYS water, sky HDR/time/weather consistency, GPU/CPU and browser tiers, lease/OOM/device-loss, material copyright and performance p95/p99/memory on original 3D biomes.

# ADR-0027 — Stable Scene/Prefab IDs and Non-Destructive Three-Way Override Rebase

**Status: PROPOSED / NOT APPROVED FOR CODE**  
**Date:** 2026-11-14 | Research #162 | WO NLE-P00-WO-002-WORLD-02 | Coding #42 OPEN/BLOCKED.

## Decision context
Stormline needs reusable scene graphs, nested prefabs, variants and property-level overrides; edits to a shared template should propagate safely to many child instances without silently deleting local changes or breaking source identity. WORLD-01 supplies ECS handles/components; DATA-02/04 own assets and persisted source. A shallow copy/deep copied prefab destroys linkage and makes undo/reimport brittle. External USD/Unity/Godot formats have incompatible ownership/license models.

## PROPOSED policy
1. **Source graph vs runtime graph:** `SceneAssetV1` and `PrefabAssetV1` hold stable NodeId/PrefabId/AssetId+revision and nesting/variant dependency DAG, separate from runtime WORLD-01 EntityGuid/EntityHandle. Structural parent in one scene is a cycle-free rooted forest; prefab inheritance and nested references form separate acyclic bounded graph. Identity is NOT name/path or raw ECS slot.
2. **Instance relationship is a link plus sparse overrides**, not an untraceable copy. Child/node/field overrides addressed by stable `{sourceNodeId, componentTypeId, fieldId}`, structural adds/removes/moves carry durable IDs and tombstones. Inheritance priority for this custom model is explicitly source base -> nested base -> variant layers -> instance patch -> authorized runtime-only state; this is not OpenUSD's exact composition strength.
3. **Propagate only non-overridden data automatically:** source updates with no competing instance override change only corresponding unmodified fields, respecting schema migration. When base+local modify same field/child in incompatible ways, perform typed **base/ours/theirs 3-way rebase** and return conflict receipt. Base removal vs local override/ref never silently deletes data. User chooses resolution; reject/record unresolved conflict.
4. **Transactional stage-preview-validate-commit:** DATA-04 owns source CAS, undo/redo+journal; WORLD-01 owns live ECS lifecycle at scheduler boundary, with separate commit+publish receipts and safe reconciliation after crash/failure. Do not claim a distributed atomic save+GPU+physics action. Undoing a base edit may conflict with later edits and must not overwrite them silently.
5. **Transforms through CORE-05:** reparent `KEEP_LOCAL` or `KEEP_WORLD`; latter uses checked inverse and representable affine result, errors for singular/sheared TRS; authored camera/world transform cannot override authoritative PHYS/NET state.
6. **Portable schema/headless:** source generated per-component stable IDs (WORLD-01), DATA-02 asset provenance and access, DATA-05 cooked snapshot/stream, no mandatory Unity/Godot/OpenUSD/O3DE runtime. Optional USD/OpenUSD interop must use **Tomorrow Open Source Technology License 1.0** exact pinned version plus third-party disclosures, not assumed Apache2; Godot MIT and O3DE Apache2 OR MIT references, Unity proprietary references only.
7. **Bound nested expansion and fan-out**, memory CPU, command buffer and I/O; on failure leave last good source and last fully published runtime scene or mark typed incomplete. No recursive loader/URL script, unrestricted file or project scope.
8. **Typed Editor/CLI/MCP parity:** inspect and stage graph changes, dry-run propagation/rebase, show before/after affected counts/rights/field-level conflicts, DATA-04 CAS commit, reversible journal. No direct world privileged network mutation, unsafe plugin scripts, cross-project source/assets or secret metadata leaks.
9. **SIOP optional PROVE-OR-DROP** incremental rebase planner; baseline full rebuild+3-way merge is correctness oracle. No novelty/performance proved. Do not auto-expand scope without benchmark and DoD.
10. **No runtime approval:** ADR-0027 remains PROPOSED, 80 code WOs BLOCKED/executor_ready=false, code #42 OPEN/BLOCKED, WORLD-01+DATA-02 code absent, release class UNDECIDED and historical CORE-04 research pending. Need approved owner DoD, context SHA and code evidence before unlock.

## Rejected alternatives as unconditional defaults
Hierarchy names/paths as primary IDs; entity handle serialized; automatically flatten nested template source; in-place clone/copy replacing originals; latest wall clock wins on simultaneous edits; recursive unbounded instance load; treating `KeepWorld` as always representable TRS; overwriting local variant override when base changes; relying on Unity editor or bundled USD runtime as mandatory source-of-truth.

## Future acceptance proof
Original prefabs edited/instanced/nested/variant into many scenes with exact field-level results and undo/redo+crash recovery, stable source/instance ID and remap, checked reparent/negative scale/shear, headless CPU and desktop/Web tests, untrusted scene parser/security/rights and p95/p99 memory/latency.

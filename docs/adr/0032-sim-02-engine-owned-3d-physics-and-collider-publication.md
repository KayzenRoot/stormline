# ADR-0032 — Engine-Owned 3D Physics, CPU-First Fixed Tick, Safe Collider Publication

**Status: PROPOSED / NOT APPROVED FOR CODE**  
**Date:** 2026-11-14 | Research #177 | NLE-P00-WO-002-SIM-02 | Coding #47 OPEN/BLOCKED.

## Context
A commercial-grade 3D game engine needs reliable rigid-body collision without hardwiring proprietary SDK types or GPU features into its public ABI. Cross-thread physics callbacks and data-driven mesh shapes risk stale entity accesses, crashes, invisible ground and unauthorized simulation changes. The vendor's deterministic CMake flag alone cannot guarantee engine-wide replay, and CUDA-only acceleration cannot be the minimum for macOS, ARM or Web. The Source Pack limits this increment to P00 research with all 80 code packets blocked.

## PROPOSED decisions
1. Original **Stormline-owned** versioned PhysicsWorld3D/Body/Shape/Constraint/Event/Query/ColliderAsset and error types with world+generation handles independent from solver IDs and ECS EntityGuid, backend ABI private; **Jolt C++ MIT leading candidate**, PhysX 5 CPU BSD-3-Clause, Rapier3D Apache-2.0, Bullet zlib alternatives, none adopted. Quantitative actual multi-OS/WASM/headless benchmarking must select final backend and pinned license/profile.
2. CORE-06 fixed timestep as only authoritative simulation clock, bounded catch-up, commands validated/sorted at PRE_STEP, immutable results/contacts staged POST_STEP, WORLD-01 ECS published at coherent barrier, GFX interpolation read-only. Contact listener cannot directly change ECS/body/assets or perform reentrant query during step; backend worker jobs integrate CORE-06 and memory CORE-03.
3. Global WorldId/WorldEpoch+body/shape/constraint slot/generation and immutable source revision handles. WORLD-02 scene/prefab source and DATA-04 durable CAS/undo versus SIM-02 runtime pose/constraint state explicitly separated; source changes stage and ACK rather than mutate during collision.
4. Units, handedness, quaternion convention and gravity fixed by approved CORE-05 and typed profile. Rebase large worlds at safe tick using local solver island and World-03 streaming/GFX/NET owner ACK; global signed assets never persist local floating solver origin as authoritative world coordinate.
5. Sphere/box/capsule/convex compound dynamic bodies; triangle mesh/heightfield static by default. Dynamic concave mesh requires explicit backend capability and risk approval rather than pretending all dynamic mesh/terrain contacts supported. Import hardening and source rights DATA-03/05, collider cook hash and parent/scale fidelity.
6. Solver-owned broadphase must **never duplicate WORLD-03 interest** or GFX-04 visibility; exact narrowphase/query refinement and stable engine IDs sorted for deterministic query/event contracts. In Jolt some broadphase queries can vary with concurrent AABB expansions, independent oracle required before claiming deterministic results. Filters/layers/permissions and contact begin/end/impulses and sensors poststep.
7. Constraints/joints feature-gated fixed/distance/hinge/slider/cone-twist/6DOF; basic constraint support does NOT implement SIM-04 ragdoll, SIM-05 vehicles or SIM-06 deformable/VFX. Validate anchor/axis/limits/motor/iteration caps, full body+joint retire semantics and source handoff.
8. **WORLD-03 critical collider publish handshake**: asset+WorldEpoch+CellId+ShapeSourceRevision validated, DATA-05 cook, PRE_STEP stage, SIM-02 physics ACK, then traversable ACTIVE cell; on failure retain last-good collision/barrier and never mark missing ground active. Memory fences/leases and dynamic cross-cell pins must be stable; S3P optional PROVE-OR-DROP optimization only.
9. Jolt `CROSS_PLATFORM_DETERMINISTIC` and Rapier enhanced-determinism optional future profile subject to same exact source/defines+ordered input, worker/precision restrictions and actual byte/semantic full-state replay on native and WASM. A snapshot limited to transforms cannot guarantee contact warm-start/constraint state rollback; NET decides replication and authoritative lockstep policy separately.
10. Safety: bounded imported shape vertices/triangles/compound depth/constraint count/contact event/query output/impulse, reject NaN/Inf and invalid normal/hull. No untrusted script/URL/cross-world pointer access, use-after-free in callbacks or partial source commits; typed recovery and quotas, security/fuzz/ASan/TSan future. Future code HIGH assurance only when gameplay money? Standard **ELEVATED** native memory and persistence risks.
11. No unlock: future #47 depends WORLD-02+CORE-03 actual merged/audited code, approved 1.0 Scope/DoD/ADR-0032, backend/source ABI selection and raw-byte SHA-256 Context Lock, actual tests and no HIGH/CRITICAL. All 80 code WOs remain BLOCKED/executor_ready=false, `approved_adr=null`/release `UNDECIDED`. Historical CORE-04 research gap remains.

## Rejected shortcuts
Making Jolt/PhysX/Rapier structs public; bypassing source-collider revision acknowledgment; relying on GPU physics or CUDA for baseline; treating dynamic triangle mesh as universal concave collider; using variable graphics delta or renderer transforms to advance physics; mutating ECS in collision callback; duplicate spatial broadphase across WORLD-03; claiming same-result replay from vendor marketing; loading unmanaged user collision binaries; implicit migration/merge unlock from docs.

## 2. Proposed semantic operations (not executable)
- `InspectReplicationCapability(Target,NET01Capabilities)`, `InspectReplicationSchema(ProfileId)`, `PreviewReplicationProfile(Project,Revision,ProposedConfig,Principal)` -> read-only redacted profile and target risks, NO network dial or ECS read. `Stage/Validate/CommitReplicationProfile` through DATA-04 expected-revision CAS, issuer rights and audit; Editor/CLI/MCP semantic parity only for authoring.
- Server-only `OpenRecipientReplicationContext(AuthenticatedMatchPrincipal,ConnectionEpoch,WorldEpoch)` -> trusted ViewerContext; `CloseRecipientReplicationContext` erases baselines and queued secret data. Not invocable from GAME-02 untrusted script or client.
- `AcquireCommittedWorldReplicationView(ValidatedWorldReadBarrier,TickId)` -> immutable SourceView; `ComputeAuthorizedFieldProjection(Viewer,WorldView)` -> policy decision; `ComputeRelevantObjects(Viewer,AllowedFields,SpatialIndexRef)` -> InterestSet. **Authorization must execute before any shared data cache or outbound packing**; client "Subscribe" cannot override access.
- `BuildReplicationSendPlan(AllowedInterestSet,PriorityPolicy,NET01Budget)`; `EncodeSnapshotOrDelta(Viewer,Baseline,Schema,Quant)` -> bounded full/delta buffer; `EnqueueReplicationFrame(ConnectionEpoch,SecureNET01Profile)` -> transport receipt not game commit; `RecordClientAppliedBaselineAck(ValidatedAck)` -> only known verified allowed context can advance a baseline.
- `InvalidateRecipientVisibility(Viewer,NewPolicyRevision)` -> immediately stop future private-field projection, invalidate pending queued private buffers/history and emit safe lifecycle visibility change. `RequestReplicationResync(Viewer,Reason)` -> authorized new keyframe; cannot re-send now-forbidden fields.
- `ObserveReplicationBudget/Stats` -> redacted per-role/aggregate evidence; `InjectSyntheticVisibility/NetworkFault` restricted future test harness only, prohibited production.

## 3. Security/lifecycle/consistency rules
1. Snapshot production requires **committed server state** from NET-02/WORLD-01 at CORE-04 TickId; no raw client Position/Health/XP or private admin fields accepted as source. NET-03 cannot commit authoritative game state. GAME-04 application receipts and NET-03 client snapshot ACK are different transaction types.
2. Policy checks are field/entity-level and *deny wins*. Denied entities must not leak ID/count/location if classified secret; permission epoch reset blocks stale private delta. Previously exposed data cannot be forced deleted from a malicious client, so never send hidden information expecting a later revoke.
3. Interest broadphase from WORLD-03 current server index, then fog/LOS/phase/owner/team filtering and hysteresis only **for already permitted objects**. If access revoked, no grace/hysteresis may keep it included. Unknown role/spectator must be denied until verified.
4. Spawn/despawn/parent and component updates use stable generational IDs and ordered dependencies. Reconnect/new match/new role and scene schema changes require new context/full baseline or explicitly proved matching visibility epoch; no stale packet applies to new world generation.
5. Delta base must be **application confirmed** for this viewer after decoder validated/frame hash, not merely NET-01 ACK. No unbounded baseline retention, unreliable snapshots are eventually consistent only under continued delivery. Resync when client ACK gap/evicted baseline/timeout; never infinite "retry delta" loop. A retransmitted delta cannot resurrect a denied actor.
6. Priority scheduling uses bounded stable ordering/age fairness and exact NET-01 transport budgets/PMTU, not unlimited reliable backlog. Critical lifecycle can have reliable path separately from transient state; control cannot be starved. Body length includes headers, auth tags and fragmentation overhead. Unknown DATAGRAM browser support is CAPABILITY_UNAVAILABLE.
7. Quantization: finite bounds/rounding/overflow/saturation/version pin; exceptions for exact critical values, no lossy physics truth loops. Compression disabled by default on secret+attacker-controlled reflective data; no secrets in shared dictionary or cross-principal cache. Compression changes do NOT alter permission checks.
8. Decoder hardened for corrupted bitstream, length, field count, decompression bombs, unknown required schema/type, object life/order. A malicious client ACK/status/interest hint cannot increase rights or request private world data.
9. Privacy: log no raw hidden entity list, per-player secret field, token/IP or decrypted snapshot. Security tests must inspect actual decoded client wire and side-channel behavior, not just filter count.

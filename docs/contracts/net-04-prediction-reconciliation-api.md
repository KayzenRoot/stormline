## 2. Proposed semantic operations, not executable
- `InspectPredictionCapabilities(Target,GameMode,NET01Features)` and `PreviewPredictionProfile(Project,ExpectedRevision,Principal,Policy)` -> read-only, redacted exact capability/options/determinism/security warnings. `StagePredictionProfile/ValidatePredictionProfile/CommitPredictionProfile` via DATA-04 source CAS, authorized role; no runtime socket, admin hitbox, private actor data or secret exposure. Same semantic diff in Editor/CLI/MCP.
- Client `CapturePredictedInput(ActorBinding,ActionFrame)` -> immutable bounded history; `AdvanceClientPrediction(CORE04_FixedTick,CanonicalSIM03Motor,History)` -> disposable local predicted movement and visual cues, never server authoritative state; `QueueIntentViaNET01` -> transport receipt (not applied input cursor).
- Client `AcceptAuthorizedSnapshot(NET03Snapshot,ServerProcessedInputCursor)` -> validates match/world/actor schema visibility and cursor; `BuildReconciliationPlan` -> bounded rollback of **client local predicted state**; `ApplyServerCorrectionAndReplay` -> ReconciliationReceipt with CPU/error/side-effect dedup; `SmoothVisualCorrection` -> rendering-only offset. Incomplete collision cohort, out-of-window ack or changed scene -> `DisablePredictionAndRequestResync`, not silently simulate unknown history.
- Client `ComputeRemoteInterpolationTimeline(AuthenticatedSnapshots,RTTJitterSamples)` and `SampleInterpolatedRemotePose` -> strictly authorized presentation; `BoundedExtrapolateOrFreeze` only when permitted and within cap.
- Server **future/optional** `CollectApprovedHitHistory(WorldCommittedBarrier,Policy)` -> immutable bounded read-only collider history; `ValidateLagCompensatedHit(AuthenticatedInput,ServerObservedTiming,History,NET06Policy)` -> GAME-04 validated intent at **current tick**, receipt to authority, never rollback of server-world, persistent inventory or scoreboard.
- Test-only `InjectSimulatedNetworkFault(Profile,Seed)`, `GoldenReplayInputTrace`, `AssertAuthorityUnchanged` require explicit test harness, production deny.

## 3. Three ACK/commit distinctions (mandatory)
`NET01_TRANSPORT_ACK` = transport delivered data; `NET03_SNAPSHOT_APPLIED_ACK` = authorized decoder applied baseline; `NET02_GAME04_INPUT_PROCESSED_RECEIPT` = server validated/applied action at TickId; `DATA04_DURABLE_COMMIT` = durable state transaction. **No interchangeability.** Replaying local prediction cannot produce GAME-04 accepted event, server hit, money/inventory reward or durable checkpoint. Predicted cosmetic cues only use local stable ID/dedup.

## 4. Correctness, security and denial
- Only NET-03 authorized view can be interpolated/predicted; do not infer hidden actor state or reproduce private collider data from server. On role/match/world/scene/owner epoch change invalidate both histories, smoothing and speculative spawn mapping, and require reauthorization NET-05/02.
- Bounded ring replays with monotonic TickId, wrap-safe inputs and server-cursor; when out of range, **hard correction or no-predict fallback** and explicit reason. Never unbounded rewind for 400ms+ jitter, invisible simulation loop or arbitrary per-frame CPU work.
- Server hit history query only if approved and authored under independent admin security, max window/body types and NET-06 fairness clamp; **client timestamp, RTT claim or replay hash are untrusted**. No client can request `GetHistoricalWorld` or arbitrary private enemy collider list. Collision at historical tick may be indeterminate due to unavailable cover history; deny or documented fair fallback.
- Fixed-step SIM-03 replay errors may arise from FP, contacts, random seed, structural entity changes, parallel scheduling or missing cohort. Do not claim bitwise deterministic cross CPU/OS/browser without real proof. Require same pinned schema/asset and known contact state on simulation replay.
- UI smoothing offset never affects physical position or hit validation. Teleports, deaths and scene transitions are explicit hard-snap cases; interpolation behind cover not a game-authoritative location.

## Oracle and fixture rules
Every future run records engine build SHA, graph/material schema versions, compiler profile/tag, node registry digest, target/OS/driver/browser, GPU/device generation, seed, graph/asset hashes, rights manifest, source revision, test ID, trace ID, raw output and semantic digest. No copyrighted game assets or unlicensed fonts/materials. Golden image tolerances must be approved against actual target devices; documentation CI is not GPU/visual proof.

- G1 graph UX: command/button registry, keyboard/focus/IME, canvas viewport, clipboard, minimap and presentation-only layout.
- G2 graph semantics: typed ports, explicit conversions, DAG, stage/domain, stable IDs, malformed graph and canonical digest.
- G3 node library/subgraphs: node definitions, interface signatures, registry/version migrations, presentation metadata and recovery.
- G4 materials: GFX-05 PBR/stylized parameters, texture bindings, alpha, normal/color semantics and provenance.
- G5 compile/preview: GFX-02 source maps/reflection/compile, GFX-01 capabilities, GFX-03 fences/device loss, GFX-06/07 preview.
- G6 variants/export: static/dynamic parameter split, native/Web profiles, MaterialX/glTF loss report and validated package receipts.
- G7 security: hostile import/clipboard/graph/compiler, capability and MCP isolation, rights and cache integrity.
- G8 platform/accessibility/performance: Windows/Linux X11+Wayland/macOS Apple Silicon/Web, screen readers, graph/compile budgets and GUI-only acceptance.

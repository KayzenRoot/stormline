# Stormline — Logo System Specification v0.1
Status: DESIGN BRIEF; nenhuma marca final produzida.

## Símbolo preferido para explorar
Monograma **S** estilizado com linguagem de linha de energia/impacto controlado. Não usar raio clipart, escudo genérico gamer, textura complexa ou cópia de símbolo existente. A geometria base deve funcionar sem gradiente.

## Três candidatos a conceituar
- A — The Strike: uma linha dinâmica com interrupções calculadas, ritmo de movimento.
- B — S Mark: monograma S proprietário, forte em tamanho pequeno; preferido para primeira exploração.
- C — The Pulse: pulso abstrato contínuo, mais orgânico, apropriado a motion.
A estratégia principal de exploração é B + traços moderados de A, **ainda não aprovada como arte**.

## Instrução ao designer / Codex
1. Inspecionar este guia e o Ledger; conferir no repositório assets existentes.
2. Definir grade geométrica e curvas/ângulos originais em SVG editável; documentar lógica de proporções.
3. Produzir três estudos, cada um com variantes flat dark/light e em 24 px, sem copiar terceiros.
4. Analisar originalidade básica, legibilidade, monocromia, equilíbrio óptico, respiro e usabilidade como ícone.
5. Entregar propostas, não declarar a identidade aprovada; pedir aceite do proprietário.
6. Após aprovação, criar asset registry com SHA, fonte SVG, variantes, licença/proveniência, exports e changelog.
7. Executar testes automatizados de validação SVG e raster quando o pipeline gráfico existir; aprovação por evidência visual.

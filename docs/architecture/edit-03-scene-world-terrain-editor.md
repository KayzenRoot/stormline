## 1. Professional editor architecture, original and separated
Propose a **Stormline-owned Scene Editing Transaction Orchestrator** that interprets typed user commands into immutable PREVIEW plans; validates selection, type metadata and ownership; stages versioned scene/terrain/prefab deltas with DATA-04 source revision; delegates real canonical mutations to WORLD/DATA owners; and emits a commit receipt plus reversible history. The viewport and inspector are clients of this service, not parallel writers. GPU preview, terrain brush overlays, procedural evaluations and undo must be **non-destructive until commit**. No implementation of editor, renderer, VFS or terrain exists in P00.

## 2. Scene tree, identity and reflection semantics
An authored scene is a canonical DATA-04 source document. Hierarchical projection uses **stable entity/node identity + generation, not fragile path**; human label/path can change without silently breaking references. The editor provides virtualized tree (100/1,000/10,000+ synthetic entities future benchmark axes), filter/tag/search, multi-select (range/ctrl/shift), parent-child drag/reparent with anti-cycle and clone/duplication semantics, explicit prefab ownership and disabled invalid operations. Scene root uniqueness / nested instance root boundaries are declared by schema owner; preserve hierarchy and dependency integrity after scene save/reload and rename.
**Selection** is an immutable set of stable refs + scene/document revision; if the entity was destroyed/unloaded, render a nonmutating stale indicator. **Inspector** consumes CORE-05 metadata type, property constraints/units/localization, composite selection tri-state/mixed values, per-component permission and provenance (local/prefab/inherited/generated). Display fields typed; no free raw memory offset. Multi-edit all-or-nothing or explicitly partial with enumerated per-entity receipts, never silently apply subset when batch atomic semantics requested.

## 3. Gizmos, transforms and picking
Transform command has explicit coordinate space **LOCAL/PARENT/WORLD**, pivot **ACTIVE/MEDIAN/INDIVIDUAL/CURSOR**, orientation axes, units (metric/angle and handedness owner), snap grid/angle/surface, axis lock and numeric text entry. Translation/rotation/scale of nested transforms requires correct parent inverse and quaternion/decomposition policy; handle **nonuniform/negative/zero scale, singular parent transform, quaternion normalization, NaN/Inf**, scale sign, rigid body constraints and world origin rebasing without precision loss. For multiple selections, stable shared pivot and parent/child overlap editing avoids applying transform twice.
Mouse ray/ID-buffer picking must resolve actual WORLD generation and **GFX frame/object generation**, reject stale GPU readback after scene edits or streamed cell unload. Drag is PREVIEW ghost transform/terrain overlay, cancellable with Escape/latency spikes; one commit transaction at pointer release or explicit confirmation, no undo record per mouse motion. Keyboard numeric precise editing and accessible alternative to pointer-only gizmo. Touch/gamepad optional role scoped, not unconditional.

## 4. Undo/redo and durable scene transactions
**Single semantic mutation path**: command invocation -> scope/permissions/loaded cell/asset refs/version preflight -> calculate typed before/after semantic delta with bounded memory -> **preview** -> atomic delegated **DATA-04 CAS** commit (+ dependent WORLD-04 terrain/World owner transaction) -> durable receipt -> scene-scoped undo/redo records. Host EDIT-01 Ctrl+Z routes to active scene undo scope; gameplay rollback is NET/GAME and unrelated. Group contiguous brush strokes into bounded commits; coalescing must not silently erase discrete user operations. Undo may be implemented via semantic inverse diff only if invariant still holds; changed assets/foreign revisions cause conflict and review rather than blind reversal. Crash after commit before UI receipt must recover using idempotency ID, no duplicate terrain sculpt or actor insertion. Multi-file scene/terrain asset changes need prepare/commit marker and verified recovery; **a single file rename is not an atomic multi-document transaction**. All power failure/durability proof FUTURE. DATA-04 owns serializer and source changes, not EDIT-03.

## 5. Prefabs and non-destructive composition
Define original PrefabDefinition stable AssetId/revision, PrefabInstance stable InstanceId + source ref and ordered **OverridePatch** (property path by stable component/field IDs, create/remove child, nested prefab link). Compute effective scene with precedence base→variants→instance overrides→manual editor layers and explicit conflict classification. Detect cycles, missing/renamed source, type change, invalid tombstones, external asset dependency and unauthorized script. Prefab *apply/revert/rebase/break link* are separate, user-reviewable operations with provenance and lossless diff; don't discard instance overrides silently during source upgrade. Nested instancing can share immutable source content but a user editing an instance must not mutate siblings except with approved "edit source" command. Scene duplication has intentional new IDs and remapped internal refs. Interop OpenUSD composition is an external adapter candidate, not Stormline native prefab syntax or license assumption.

## 6. World partition, streaming and large-world coordinate policy
WORLD-04 is authority for terrain topology and streaming cell representation. EDIT-03 exposes a **spatial cell editor** keyed by stable cell ID/LOD/version and world origin double-precision *editor coordinates* where required, with explicit local origin conversion when passing floats to render. Selection/lock includes cell generation, loaded/unloaded/dirty/pending state, dependencies and streaming budget. Background load/unload cannot detach dirty cells without DATA-04 save/confirmed quarantine. Scene panel can show unloaded cells as metadata placeholders, never silently drop their authored content.
Partition choices: fixed grid/hierarchical quadtree for heightfield candidate, octree for volumetric scene candidate, streaming HLOD for render candidate, **not adopted**. Hot cell boundaries, paint across seams, cracks, normals, stitching and foliage density must be regression-tested. A 2D scene and a 3D terrain may share metadata but not force same partition/physics layer. **Unreal World Partition and One File Per Actor** are references, not code/license to import.

## 7. Terrain: heightfield, splatmaps, vegetation and layers
Terrain editor orchestrates WORLD-04’s canonical heightfield/mesh/volume model (selection TBD), **composable non-destructive layers**: BASE, SCULPT(height delta), SMOOTH/EROSION(seed+version), MATERIAL/WEIGHT masks, FOLIAGE density/instances, HOLES, WATER/SPLINE and PROCEDURAL source handles. Every brush is a typed stroke with radius/strength/falloff, world-space samples resampled at deterministic distance/time, random seed pinned, affected tile refs, prior/source generation, bounded area/energy/time and preview overlay, **not direct GPU-only state**. Brush modes raise/lower/smooth/flatten/stamp/erosion/paint/erase, pressure optional after secure validation. Shared terrain tiles avoid seams with neighbor halo/stitch semantics and deterministic fixed precision/quantization policy; GPU preview may be approximate but CPU or authoritative WORLD result must match spec within approved tolerance.
Separate virtual source layer from baked LOD/mesh output and cached GPU splatmaps, which are regenerable. Foliage placement uses stable instance IDs with deterministic per-cell seed and density budget; undo restores vegetation refs and mask tile before/after. Live bake/LOD/procedural regeneration never overwrites manual layers without explicit conflict migration. Terrain heightfield **cannot represent caves/overhangs**; unsupported voxel/mesh mode must be flagged rather than falsely supported.
No immediate procedural generator created here: WORLD-05 owns that future feature and WORLD-04 owns terrain serialization.

## 8. Preview/performance/platform/accessibility and safety
Editor UI event loop and viewport picking async, streaming/terrain sampling background bounded/cancellable; overlay is eventually consistent with committed scene revision, stale picks/preview results ignored. GPU GFX-01 device-loss preserves scene source/deltas and selection; edit functionality can degrade to hierarchy+inspector with no fake GPU visual. Perf axes: 1k/10k/100k+ entities; 4/16/64 dirty cells; brush radius/tile density and foliage 1k/100k instances; scene save/undo history size and CPU/VRAM streaming. **These are experimental scales, not capacity targets**; thresholds TBD after owner-approved hardware baseline.
Windows/Linux X11+Wayland/macOS DPI/IME/keyboard and accessible scene hierarchy/inspector, visible focus, readout of gizmo numeric operations; pointer-only brush gets keyboard-accessible alternatives for essential operations where practical. No WCAG certification by documentary assertion. Undo/save must survive broken plugin, OS kill, disk full, asset hot reload, scene schema mismatch.
Untrusted scene/prefab/brush texture/heightmap file, asset URI, data URI, custom shader and plugin can contain malicious references, recursive cycles, oversized arrays, decompression bombs, arbitrary script or path escape. Guard via DATA-01 VFS nofollow and quotas, CORE-05 type allowlist, DATA-02 provenance; plugin native code is **not sandboxed by simple capability list**, require isolation or reviewed trust. AI/MCP sees same semantic command authority with project/cell/asset scopes and DATA-04 expected revision, preview/approval for destructive terrain bake, mass erase, apply-to-source or paid service, never arbitrary exec/file read. Redact raw user paths/secrets in logs.

## Risk controls and threat model
- **Sampling bias:** instrumentation itself can cause stalls, GPU queries and hardware counters may serialize work; compare profiler-on/off independently with same env. Never silently subtract overhead to manufacture improvement.
- **Clocks and statistics:** mismatch between GPU clocks, CPU time, present events, query rollover/valid bits, thermal ramp, VRR refresh, background process, scheduler and dropped frames. Invalid or missing data -> typed error, not zero-ms filler.
- **Memory:** dynamic budget sample cadence/coarse estimates/CPU+GPU shared pages; don't sum shared memory twice. Device loss, paging and OOM are failures not dismissed outliers.
- **Privileges:** no self-hosted runner executes unknown PR with hardware admin/root; perf_event_paranoid and DXGI/Metal permissions checked, no setStablePowerState outside approved developer mode or user machine control.
- **Privacy:** trace file may include scene paths, shader sources, GPU/user device fingerprint, source locations, input events, screenshots and proprietary assets; default local-only/opt-in, redact/harden/artifact retention and hash, no public CI upload of private user project, no remote profiler daemon on public interface.
- **Data integrity:** malicious trace/profile JSON, injected units, statistical report spoofing, untrusted scene script/asset parser, CSV formula injection and zip bomb; size/parse quotas, no string interpolation to shells, immutable raw data with SHA and permission.
- **Cost/greenwashing:** free public standard hosted compute is not free physical GPUs nor free unlimited artifact storage, pro UX SaaS/cloud can charge; owner R$0 hard guard, no API key or paid accounts. No p99/VRAM “optimized” claims without raw actual traces and QA-02 golden correctness.
- **Energy:** real power meter/counter needed for joules; inferred software metrics from CPU/GPU utilization are estimates only; distinguish battery AC and ambient thermal; do not collect personal health/behavior data.
- **Licenses:** exact upstream plugin/vendor driver dependencies and bundled shader assets reviewed. NLE-D009 engine license is OPEN, no public proprietary shipping authorization.

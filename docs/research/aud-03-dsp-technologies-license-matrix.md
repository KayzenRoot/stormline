## Technical selection, ABI and sandbox protocol
1. **Start from own reference kernels** for gain, bypass, stable peaking EQ biquad, finite compressor dynamics and bounded delay; select a library only when a measured acceptance/maintenance benefit is proven against correctly licensed reference.
2. Use one AUD-01 mixer and sample clock; attach DSP as pure processing plan to the bus/voice, never a duplicate device/mixer. FFT algorithms process only preallocated buffers: verify pocketfft allocation behavior and KissFFT plan creation separately.
3. Explicitly test `NaN/Inf`, denormals, high Q/resonance, extreme gain, invalid delays and channel layouts, sample rate changes, automation bursts, feedback loops, tail + latency compensation. "Smooth" or "low CPU" must be measured with reference original PCM, not vendor marketing.
4. For Faust generated code, freeze complete `.dsp`, included libraries/architecture files and their file-level SPDX licenses; compiled output may carry copyleft due to input, despite compiler's own license. No automatic "free generated code" assumption.
5. For CLAP/LV2: source licensing and **execution trust are orthogonal**. Native plugin host ABI does not prevent filesystem access, networking, kernel crashes, data exposure, CPU hogging or blocking. First slice **forbids untrusted plugin loading**. Later plugin bridge needs explicit opt-in, isolated process/limited rights or audited sandbox (e.g. WASM with restricted imports), nonblocking shared ring, watchdog/fallback, crash recovery, and budget measured before approval.
6. Confirm exact source tag/commit, API/ABI, LICENSE/NOTICE and indirect dependencies, OS/architecture compiler support (Win/Linux/macOS/ARM/Web) and licensing model NLE-D009. Do not bundle copyrighted plugin presets/impulse response/music samples without verified rights.
7. Future measured comparison uses original legally-clear sinusoid/sweep/impulse/noise signals, amplitude/frequency/phase, THD+N, alias rejection, p50/p95/p99 per-node CPU and real device callback XRUN/failure, exact Git build fingerprint. No results today.

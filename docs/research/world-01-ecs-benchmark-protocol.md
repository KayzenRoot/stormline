**WO NLE-P00-WO-002-WORLD-01 / research #159 | Future only, NOT EXECUTED.** No numeric throughput, allocator use, entity-count capacity, static safety, cross-platform ABI or perf measurement recorded.

## Test tracks and controls
1. **Identity/ref golden:** own deterministic seed scripts create/destroy/recreate GUIDs and handles, world clone, remount/unload, generation max, late async dereference, corrupted/duplicate GUID and epoch changes; compare slot/epoch/generation reference model including counterexample trace. A fast ECS that reuses a stale entity handle is a FAIL.
2. **Query hot path:** 10^3, 10^4, 10^5, 10^6 synthetic entities as **workload sizes only**, mix Position/Velocity/Health/Renderable/CollisionRef/AIState and authoring tags. Independent matching query oracle for includes/excludes/options/changed, sorted deterministic replay and default order-agnostic cases. Compare archetype/SoA vs sparse set vs hybrid candidate only with identical correct results/allocator settings.
3. **High-churn structural operations:** repeated spawn/despawn, add/remove tag/component, hot-reload schema version and fragmented archetypes; stage commands across workers, fixed operation budget and exact command issuer/sequence ordering with CORE jobs. Record sync point time, memory migration and stale borrow prevention, OOM/failure atomicity and observer dedup.
4. **Authoring and persistence:** multi-scene world save/reopen with DATA-04 journal and schema migration, editor CAS conflicts, undo/redo and read-only inspection. GUID stability on reload with new runtime handles, secrets rights and transaction recovery. Test with and without GPU/headless to confirm independence; actual engine source required.
5. **Cross-platform and security:** native Windows MSVC and Clang x64, Linux Clang/GCC x64 and ARM64 as approved, macOS Apple Silicon, browser WASM/Emscripten. Compile with actual C++ standard toolchains and compare portable generated reflection to optional C++26 reflection only when feature detected. TSan/ASan/UBSan where available; generate fuzz schema collisions, illegal command buffers, oversize component pages, cross-world/client authority.
6. **C++ ecosystem comparison:** optional Flecs MIT v4.1 archetype/deferred commands, EnTT MIT candidate sparse set and Bevy ECS MIT OR Apache-2 reference. Own clean-room interface and identical original benchmark code; no vendor marketing throughput accepted as proof. Pin license/version and record SBOM for any actual integration only after approval.

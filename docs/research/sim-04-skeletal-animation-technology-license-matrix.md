## Proposed fit-for-purpose decision protocol
1. Generate controlled original synthetic skeletons (humanoid, quadruped, asymmetric, sparse and deep hierarchy) plus legal source/rights manifest; import via DATA-03 once implemented.
2. Pin exact ozz/ACL source tags, commits, toolchain/SIMD flags, platform and transitive licenses. Examine runtime-only build vs converter/test dependency closure; preserve MIT notices and SBOM.
3. Bench **one coherent runtime clip representation per profile**: ozz/native sampling baseline; ACL decompression against common pose layout only after an explicit adapter. No unsupported assertion that ACL automatically compresses ozz runtime streams.
4. Measure visual error (local rot/trans, world-space FK end-effector, skin deformation), pose artifact quality, root displacement and marker stability; compression ratio including metadata and cold/warm decode time. Compression thresholds remain UNAPPROVED.
5. Exercise headless deterministic input order/reproducible numeric settings and Web memory limits; GPU skinning is separate GFX feature. Publish build matrix and all licenses before a code ADR can move from PROPOSED to APPROVED.

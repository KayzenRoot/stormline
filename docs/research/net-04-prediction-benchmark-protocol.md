## 4. Metrics and methodology
- **Client responsiveness:** timestamp local input capture to actual rendered visual feedback, separate NET-01 packet RTT, game authority input accept TickId and server snapshot age; latency never artificially improved by comparing client prediction to delayed server receipt without labeling.
- **Correction magnitude:** Euclidean position error (with units), orientation angular error, velocity/contact divergence, time to settle, fraction of frames hard-snap, overshoot/visible jerk and correction frequency, per game mode/actor class. Quantization tolerance from NET-03 is separate from physics mismatch.
- **Replay cost:** actual per-frame client CPU spent resimulating, #ticks replayed, p50/p95/p99 and maximum, ring memory, worst-case collision cohort CPU, scheduler stalls, number of missed game render deadlines. Measure baseline without prediction and owner-motor only; don't assume faster due to local code.
- **Remote interpolation:** delayed presentation age, buffer underrun/overrun, jitter, extrapolate/freeze durations and visual stutter; separate authorized per-recipient snapshots. No hidden player leakage.
- **Time sync:** uncertainty bounds, offset/RTT jitter drift and correction slew; measure one-way latency only with cross-host clock sync proof, otherwise use RTT. Client-reported "shot timestamp" never authoritative.
- **Hit fairness:** false positives/negatives vs controlled ground-truth timeline, peeker advantage and target-behind-cover artifacts, high/low RTT cohort, intentional delay attack, cover changes; measure both attacker and victim with NET-06 limits and no reward duplication.
- **Statistical credibility:** reproducible emulator seed + isolated real LAN comparison, repeated warmups/trials with enough independent samples for tail stats; p99 from 10 samples invalid. Confidence intervals, hardware thermal governor, CI exact SHA and raw redacted traces. No public DDoS or live player stress without consent.
- **Security:** forged client state/RTT/timestamp/hit, replay old session epoch, hidden target query, malicious low FPS clock skew and 0-RTT mutation, payload fuzz/NaN overflow/CPU amplification, per-actor quota. HIGH/CRITICAL authority/privacy/durability issues -> BLOCKED.
- **Acceptance budgets:** only after pilot and owner Scope/DoD/architecture approval. The fixture 8/16/32/64 or 120Hz is **not** a promised feature. Actual games are 2D/ARPG/shooter/vehicle genre dependent, pick profiles based on benchmark evidence.

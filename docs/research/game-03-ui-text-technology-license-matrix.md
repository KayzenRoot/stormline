## Comparative architecture alternatives
**A. Engine-owned semantic tree + focused Yoga + HarfBuzz + FreeType + ICU/CLDR.** Strong separation of permissions and public API; requires first-party widgets, text cache/IME/focus/accessibility effort. **Recommended research hypothesis**, not a selected stack.

**B. RmlUi as UI/widget/layout system, HarfBuzz/FreeType/ICU as validated text backend**. Faster feature baseline but evaluate markup parser, script modules, DOM-like state, internal focus ownership, layout and data binding against GAME-01/02 and security/import restrictions. Do NOT adopt Yoga at the same time as an independent layout authority.

**C. Own minimal layout/widget subset + same HarfBuzz/FreeType/ICU text stack.** Could suit tiny NECESSARY first slice but dangerous if custom full Unicode layout/shaping or accessibility is reinvented. Compare limited first-party constraint solver fairly.

**D. Skia or other renderer-first framework** is not justified as a mandatory alternative to existing TWO-01/glyph Canvas/GFX-07. If included only for benchmark CPU reference or offline authoring, provenance and ABI isolation required.

## Licensing, source and privacy gate
1. Distinguish **UI library** (Yoga MIT/RmlUi MIT) from **shaping library** (HarfBuzz Old MIT + file-specific notices), **rasterizer** (FreeType FTL **or** GPLv2), **locale data/library** (ICU/CLDR Unicode-3.0 and bundled terms), **font assets** (each Noto OFL 1.1) and **original translations/text** (separate rights/consent).
2. No remote font download, CSS external references, script/url markup or unvetted SVG parsing; import through DATA-03 checked rights/sizes/format.
3. Parse malicious Unicode/bidi invisible controls/RTL isolates, deeply nested rich text and malformed font tables using bounds and fuzz/sanitizer before shipping. HTML escaping alone does not provide correct bidi isolation.
4. Native Windows/Linux/macOS and planned Web/headless packaging must be tested; no assumption that headless produces a visual screenshot or screen reader native API works.
5. Pin license, origin, version/hash, binary notices, font subsetting/derivative reserved names, ICU data version, test corpora rights and target costs only after ADR approval and actual hardware evidence.
6. No runtime/font/graph/screenshot/translation imported, executed or measured in this P00. NLE-D009 engine license remains OPEN.

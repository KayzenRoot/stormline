## Explicit warnings
- **Jolt** license is MIT per upstream LICENSE; Jolt 5.6 docs are a reference, but freeze version, source and all build defines before adopting. Its architecture warns that non-exact broadphase queries can produce nondeterministic candidate sets under concurrency. The flag does not make Stormline's gameplay events/NET engine deterministic automatically.
- **PhysX 5** CPU source LICENSE BSD-3-Clause; NVIDIA docs explain CUDA GPU rigid bodies on compatible platforms. GPU binary redistribution and driver requirements require separate review, CPU build is the portable design baseline. **Do not assert PhysX GPU is open-source or supported on macOS/Web**.
- **Rapier 3D** current Rust crate carries Apache-2.0 and optional enhanced-determinism; its cross-platform byte replay depends on exact build flags, input order, SIMD and source revisions. Rust FFI/WASM is plausible from official bindings but build/asset size, latency and long-term API ABI need measured test.
- **Bullet Physics** core zlib license, but upstream LICENSE explicitly excludes Extras/examples/ThirdPartyLibs. Do not copy example art or vendored integration code assuming uniform rights.
- No SDK, DLL, GPU binary, third-party art, sample test physics world or benchmark imported. Release class UNDECIDED, no approved code ADR, no running Stormline physics. Compare cost and physics correctness, not merely feature checkboxes.

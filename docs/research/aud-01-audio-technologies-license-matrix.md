## Decision and legal gates
1. Pick one device adapter after comparing minimal external dependencies against current CORE-01 SDL3 candidate and miniaudio. **No selection now**. Do not include duplicate high-level decoder/mixer paths accidentally when wrapping a full audio engine. Public Stormline ABI must hide SDL/miniaudio pointers and sample-buffer lifetimes.
2. Confirm exact tags/commits and license files, copyright/attribution notices, codec patent/format responsibilities, any static/dynamic requirements, platform backend system libraries, release CI and SBOM. Open code distribution license NLE-D009 must be resolved separately.
3. Request Windows WASAPI shared/exclusive, macOS CoreAudio, Linux PipeWire/PulseAudio/ALSA/JACK and browser AudioWorklet capability/perf tests **only after code**. Multi-device clock synchronization, channel labels and hotplug teardown need real driver testing. OSX/Windows/Linux backend stated support ≠ measured safety or guaranteed 5 ms latency.
4. If vendor library already provides audio mixing, benchmark against Stormline owned mix semantics (headless offline and native). Avoid extra conversions, copies, duplicate gain/pan, locking and quality loss. Codec sources decode on CORE-03 worker and DATA-03/05 validated import/cook.
5. Include original/royalty-cleared tone, noise, impulse and stream audio fixtures and their license/provenance. Third-party background music/sample content is not licensed for reuse merely by permissive playback codec.

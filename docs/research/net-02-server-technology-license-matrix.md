## 3. Integration and licensing gates before any dependency
- Preserve **Stormline-owned native game simulation**; cloud/orchestrator addons never define game serialization, TickId or score. Freeze release class, source license and plugin/SDK exact version hash, compiler/OS/arch and ABI.
- Check SPDX/NOTICE, transitive/commercial dependencies, source code use, license compatibility, patent grants, logging/SBOM/CVE response, image provenance/digest, platform support and server redistribution, public endpoints/rates/quotas and privacy (GDPR/LGPD).
- Never import proprietary Unreal/Unity/Valve SDK source or content into Stormline without explicit legal rights. Valve Source 1 SDK is specially restricted even if visible in a public GitHub repository; do not label MIT.
- Security: validate server-only authoritative command gateway and distinct game receipts; network TLS via NET-01, NET-05 issued identities, NET-06 rate/abuse; no exposure of unrestricted admin APIs or private lobby secrets. Do not let automation provision paid cloud, billing or public ports without explicit owner approval.
- Once approved, benchmark local bare-metal first, then OCI and optional Agones under same scenario; compare process CPU/memory/tick and deployment cost separately; one node/one match success is not cluster failover proof.
- **No adopted third-party code, hosting contract, license, runtime or benchmark result** in this research. All 80 coding WOs stay BLOCKED.

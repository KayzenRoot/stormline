# EDIT-01 — Editor UI Toolkit, OS Integration, Viewport, Security and License Matrix

**Primary-source research, 2026-11-15.** All libraries/approaches are candidates only. No SDK, binaries, source, build system, GUI implementation or platform adapter adopted. Engine licensing **NLE-D009 OPEN**, ADR-0053 PROPOSED. Pin exact versions, file-level SPDX/NOTICE, transitive libraries, deployment form and legal rights before selection. Licenses on vendor **docs or examples** differ from code and partner contracts. "Open source" does not mean license-obligation-free or accessibility guaranteed.

## 2. Platform integration requirements, not implied support
| Host | Issues to confirm with actual build and monitors | Future evidence |
|---|---|---|
| **Windows 10/11** | per-monitor v2 DPI, DWM composition, taskbar/safe work area, device loss/DXGI or Vulkan, Alt+Tab/focus, Win-key reserved shortcuts, IME, screen-reader UI Automation | cold/warm startup, docking, unplug/plug 2 monitors with 100/150/200% scaling, NVDA screen reader, keyboard path, saved layout restore |
| **Linux X11** | display geometry negative coordinates/WM decorations, drag across monitors, scale transform, XInput/IME and AT-SPI, Vulkan/OpenGL window context | multiwindow/floating, xrandr hotplug, reconnect, Orca, IME and clipboard permission |
| **Linux Wayland** | compositor owns position, independent fractional scaling/window decoration, popup/drag restrictions, GPU context + clipboard/portal sandbox | do NOT promise setPosition absolute on Wayland, fallback to primary visible workspace and report feature capabilities |
| **macOS** | Cocoa native window lifecycle, Retina backing scale, app activation, Mission Control full screen/Spaces, Apple input method/VoiceOver, Metal layer/viewport | external screen/Retina hotplug, AX focus semantics, app background/foreground and safe device loss |
| **Web** (future integration) | browser sandbox and DOM accessibility, WebGL/WebGPU/WebView constraints, native editor not automatically browser export | distinguish browser content creation target vs editor itself, no fake native Web backend promise |

**DPI correctness:** use DIP/logical sizes in layout, raster pixels for swapchain, per-monitor scale, UI text scale and font/shaping quality, not multiply twice. Monitor EDID/serial and exact private screen arrangement need not persist. Missing monitor => reachable primary fallback. Avoid GPU blocking the UI event loop; renderer owns graphics/surface, not toolkit widgets.

## 4. Upstream source/compatibility inspection and no-claims
- Qt QMainWindow documentation explicitly says **do not pass untrusted state bytes to restoreState** because nested layouts fields may not be bounds-checked once a version/magic matches; treat as security design blocker for shared/synced workspace until app validates trustworthy origin. Native Widgets may expose QAccessible roles/actions, but custom viewport widgets still need accessible interfaces. [Qt docs](https://doc.qt.io/qt-6/qmainwindow.html), [accessibility](https://doc.qt.io/qt-6/accessible-qwidget.html).
- Dear ImGui docking is in maintained **docking** branch; multi-viewports also branch-specific, with platform backend-specific context handling. [Official docking](https://github.com/ocornut/imgui/wiki/Docking), [viewport guide](https://github.com/ocornut/imgui/wiki/Multi-Viewports). MIT does NOT guarantee native text shaping, accessible tree or Wayland absolute window positioning.
- Slint framework has **three license paths**, royalty-free proprietary requires stated conditions/attribution and commercial option for different uses; do not label entire framework MIT because docs/examples are MIT. [Slint LICENSE](https://github.com/slint-ui/slint/blob/master/LICENSE.md).
- Tauri WebView capabilities can **combine** when same window/webview appears in multiple capability sets, and capabilities do not protect insecure Rust backend or webview vulnerabilities. [Tauri capabilities](https://tauri.app/security/capabilities/).
- All third-party font files/assets, themes, icon sets and UI screenshots are separately licensed; original Stormline art branding and no font binaries shared in docs. Pin build SHA/architecture, notarization/signing and rollback before any product distribution. No choice yet, no measured performance/compatibility/assistive support and no code/SDK imported.

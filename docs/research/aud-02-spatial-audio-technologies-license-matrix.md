## Selection / preflight protocol
1. Freeze user-approved smallest NECESSARY slice: owned headphone/speaker panning, basic distance+direct ray occlusion on an original wall/door, sound source/listener pose and known world revisions, via one AUD-01 future NullSink. Select library **only after** real profiling and legal checks.
2. Compare Steam Audio direct/HRTF path as a private adapter vs Stormline-owned lightweight panner and optional libmysofa SOFA import. Do not add Steam Audio's mixing or native device routing if AUD-01 must remain sole mixer.
3. Acoustic geometry source: WORLD-02/03/04 owns scene/terrain/stream source, SIM-02 physics collisions; Embree merely an **optional accelerated ray intersection tool** in CORE-03 worker, not a solver/simulation clock. Must validate triangle budgets, source epoch and world-origin shift.
4. Before HRTF/IR data distribution: pin exact SOFA conventions, dataset copyright/license/attribution, ability to redistribute built-in HRIR and generated derivatives, output headset and privacy/consent for individual profiles. No sample HRTF files imported in P00.
5. Evaluate actual Windows/Linux/macOS native build/OS codec/device, Headless CPU, browser/WASM fallback (not every native HRTF/Embree source builds to Web), CPU p95/p99, convolution taps and spatial localization blind listening. Only then approve numerical caps and selected vendor versions.
6. Scene-bake and ray/path budgets need explicit measured acceptance and rollback. Reflections/late reverb/convolution execution belongs planned AUD-03 DSP extension when appropriate; no heavy ray/path work in RT callback.

# TWO-03 — Reproducible Animation, Timeline and Audio Sync Benchmark Protocol

**WO NLE-P00-WO-002-TWO-03, research #153 | PROPOSED ONLY | NO TEST OR EXPORT RUN**.

## Future experimental tracks
1. **Deterministic timing:** owned clip at 24, 30, 60 and 24000/1001 FPS; audio 44100/48000Hz, keyframe holds, clip nesting, cross-fades, seeks/loops/reverse, pause, timeline hour-scale and overflow at signed64 bounds. Derive exact rational frame timestamps and audio sample indices by checked arithmetic, compare to independent CPU golden.
2. **Animation visual correctness:** independently authored pixel-art flipbook, spine-like bone cutout with weighted mesh, IK and slot masks, 1D blending/optional 2D blend, offscreen hidden emitter and atlas repack. Capture bone/vertex/Canvas painter order oracles. GPU skinning only if platform supported and compare to CPU pose numerical tolerance.
3. **Cue/event replay:** owned footstep/hit/VFX cues and authoritative WORLD/PHYS acceptance, fixed simulation ticks and artificially dropped/racing renderer frames. Test intentional seek and loop semantic policies; count duplicate/missed events and stable cue IDs; visual GPU transforms never server gameplay authority.
4. **Audio/video schedule versus actual sync:** generate rights-cleared synthetic 1 kHz audio pulses/claps at agreed timeline timestamps plus visual flash/timecode marker on matching video frames. Compare planned rational sample offsets to AUDIO-owner accepted sample positions and **decoded media** timestamps/pulses from export module. Freeze codec sample rate/frame rate, pre-roll, buffering and encoder delay; measure mean/p95/p99 absolute audiovisual alignment error and drift over short/long sequences. No claim of hardware sample accuracy until real device capture.
5. **Stress/hardware:** named Windows DX12/Vulkan, Linux Vulkan, macOS Metal, WebGPU/limited WebGL2, headless CPU reference. Synthetic 100/1000/10000 active animations are workload parameters, **not** product throughput commitments. Measure CPU clip/curve/state/IK eval, optional GPU skin+Canvas submit, VRAM/UMA and asset upload, total render frame p50/p95/p99, power if available, cache cold/warm and rapid scene unload/device loss.
6. **Competitor/legal study:** Godot AnimationTree and DragonBones open source as **public design references**, Spine/Rive/Lottie only compatible external formats/rights where permitted. Compare original equal rigs/scenes and licensed media only, never vendor/competitor screenshots/source/asset extraction, anti-cheat bypass or proprietary runtime bundle.

## Reproducible controls
- Capture repository base/head SHA, compiler/build, driver/backend/OS and audio device, sample rate, latency and buffer, audio backend/mixer, monitor refresh/render scale, frame cap, scene/revision/asset+media hashes/licenses, exact rational sequence timebase, authored cue policies, source and exported mux codec flags, encoder delay compensation, number of runs/warmups and device provenance.
- Record raw event log and per-frame timeline time vs scheduled sample index and actual AUDIO/decoded-media offsets; label `MEASURED`, `PREDICTED` and `UNKNOWN` separately. No fake GPU time from static previews. Require independent golden image+audio checks and physical listener perception tests if user-facing sync claim is made.
- Compare CPU/GPU cost at equivalent pose/cutscene quality, timing correctness under dropped frames, duplicate/missing cue count, target platform audio drift and memory pressure. Quicker frames without timely sound are not an animation quality win.
- **STS prove-or-drop:** compare rational scheduling validator to basic interval/event unit checks, track true defects caught, false positives, CPU+authoring latency and comprehensibility. Reject if complexity/regressions exceed benefit.
- Future evidence bundle includes scripts, reference fixtures, benchmark logs/videos, waveform/pulse detections, rights receipts, actual native/Web builds and source+media hashes. **NO evidence produced yet.**

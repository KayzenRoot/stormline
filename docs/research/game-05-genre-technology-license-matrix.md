## Comparison criteria, recommendation and unresolved decisions
**Leading candidate:** Stormline-owned typed authoring manifest/capability graph and original synthetic fixture recipes using existing GAME/WORLD/DATA contracts, with *no new required third-party runtime*. Compare simple shared-manifest approach against plugin-style (O3DE Gems, Bevy, Unreal Lyra) and game-project-as-consumer (Stride, Godot). Risks: dependency diamond collisions, schema migration, template-to-engine coupling, asset rights, license contamination, multi-target capability honesty, supply-chain/data-only scripting escapes. Unsupported/unknown target must return explicit failed capability receipt, not a purported export.

**Exact future pin checklist:** license/source commit SHA, path-specific asset permissions, CC BY attribution/CC BY-SA compatibility, copyright/trademark originality, binary redistribution, third-party SPDX/NOTICE and SBOM, security scan, material provenance, ABI/toolchain, source CAS and output reproducibility, revocation strategy for assets/packages.

## 3. Technical policy matrix (proposed, not implemented)
| Mode | Typical actor and data | Strength | Why it may be unavailable/unsafe |
|---|---|---|---|
| OWNER_MOVEMENT_PREDICTED | locally owned character with replayable SIM-03 deterministic subset | lowest perceived input response, local feedback | CPU replays, FP divergence, partial collision cohorts, ownership mismatch and exhausted ring |
| INTERPOLATED_REMOTE | authorized distant opponents/NPCs via NET-03 snapshot buffer | stable motion under jitter with delayed timeline | no authorized pair, scene/role revocation, predicted combat authority impossible |
| LIMITED_EXTRAPOLATED_REMOTE | rare burst-lost remote actor under explicit cap | avoids immediate stop | overshoot/through walls, hidden-player inference, security and incorrect hit feedback |
| SERVER_READ_ONLY_HIT_REWIND | optional authoritative shooter hitscan collider history | compensate some display delay | peeker advantage, forged time, moving cover, high RTT abuse; server-side game-policy opt-in only |
| NO_PREDICTION | unsupported target/genre, expensive/unstable physics | simple strong server-only fallback | user-perceived delay; not a failure of security |
| GLOBAL_ROLLBACK | all-world server rewind/replay | potentially game-specific deterministic rollback | **REJECT as generic default** due to economy/durable state, capacity and non-determinism |

## 4. Real adoption/proof gates
- Pin *actual* license and package versions at build before redistributing anything; no copying Valve SDK or Unreal/Unity source into Stormline, even if publicly readable. Engine NLE-D009 unresolved. Compare native CPU x86-64/ARM, Windows/Linux/macOS, headless and browser runtime **separately**.
- NET-04 is logic over NET-01 secure delivery, NET-03 authorized snapshots and SIM-03 canonical motor, never a new crypto library, physics engine, time-sync authority, ECS or render engine.
- Validate replay deterministic envelope under same pinned binaries/assets/FP config; no cross-arch bitwise claims. Verify jitter/burst loss and partial snapshots, predicted spawn collision, role revocation and low FPS. BENCH future only; no exact latency/ticks/corrections SLA until owner approves baseline.
- Copyright/asset/license, cheat fairness and security are gates; external SDK/services not mandatory. 128 future N04 tests not executed; no engine compiled.

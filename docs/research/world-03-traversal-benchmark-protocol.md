## Workload scenes and deterministic traces
1. **Canonical wide world**: original licensed 2D tile + 3D terrain/settlements/props and mixed 2.5D billboards, source CellId/AssetId/source-revision hashes. Use synthetic 1k/10k/100k+ cells as controlled candidate workload input only; not a statement that Stormline can load them. Include 10m/100m/1000m region patterns, vertical caves and large spanning actor, empty/clustered/moving objects and irregular density; no competitor artwork.
2. **Traversal path**: deterministic camera-player 360° turn, slow walk, fast vehicle, flight over dense cells, path along exact cell boundaries, instant teleport, two-camera split-screen, world unload/reload, negative/huge global coords and precision rebasing; record expected interest+required collision pins and source epoch.
3. **Critical authority**: local player/collider+PHYS, AI/quest and NET authoritative interest may remain pinned out of view; audio source streaming; editor spectator has no gameplay/replication authority. Inject cross-world client and malicious huge radius requests with asset/cell rights.
4. **I/O and staging fault matrix**: cold/warm SSD, slow drive/HDD, optional throttled local network/storage and browser fetch/cache under capped memory, decompression latency and integrity fail, cancel after teleport, duplicate completion, delayed callback, CPU partial staged state, GPU lost/recovery, partial PHYS ACK and source revision changed midload. Never hide safe loading barrier behind missing colliders.
5. **Index alternatives**: sparse cell grid with loose dynamic BVH vs loose octree and Boost.Geometry R-tree/libspatialindex optional adapters. Query exact/approx vs independent brute-force golden; stress dense overlap, moving entities, multi-cell proxies, out-of-resident completeness. Same dataset, allocator, cache and compiler.
6. **Origin/coherence**: global integer/64bit candidate vs floating render-relative snapshot and origin epoch, physics contact stability under rebase, split-screen independent origin, stale temporal history GFX-07 and NET global replication. Compare absolute vs local position drift at high coordinate magnitudes using independently computed precise oracle.

## Candidate comparison: do not conflate editor and runtime
| Design dimension | Recommended *research hypothesis* | Alternative and tradeoff | Proof gate |
|---|---|---|---|
| 2D Canvas preview | Existing TWO-01 Canvas2DScene and GFX-07 CameraRenderView, EDIT-04 overlays only | Separate CPU/DOM mock preview drifts from runtime | Golden pixel/round-trip selection at DPI, alpha order, device loss |
| Tilemap editing | TWO-02 signed64 sparse chunk + deterministic terrain rules | Tiled GID as internal ID is unstable; Godot signed16 serialized coords insufficient for long worlds | Negative chunk boundary, rules, save/reopen/invalidation |
| UI layout | Reuse GAME-03 semantic tree/layout, compare Yoga/RmlUi/first-party only in GAME-03 | Second layout backend creates divergent focus/RTL/measure | Snapshot geometry diff across OS, fonts, locales and sizes |
| Text | Reuse GAME-03 UAX shaping pipeline, TWO-01 glyph atlas | Direct Unicode codepoint quads break complex scripts | Grapheme caret, Arabic/Indic shaping, fallback licenses |
| Timeline | TWO-03 authoritative rational time and tracks | Float wall-clock editor-only timeline accumulates drift | Golden timebase seek/loop/reverse and pure preview |
| Storage | DATA-04 CAS source transaction and journal with undo domain | UI file writes or direct scene serialization create integrity forks | Crash injection/reopen/rollback and stale-revision rejection |
| UI controls/buttons | EDIT-01 namespaced command registry with GAME-03 preview semantics | Icon-only toolbar or hardcoded shortcuts inaccessible | Keyboard/gamepad/IME/reader checks with modal/focus changes |

## Threat model and fail-closed requirements
**Untrusted inputs:** PNG/JPG/SVG/fonts, compressed TMX/JSON/LDtk archives, external paths/URLs, tile metadata/script fields, oversized layers/chunks/coords, malformed gradient/transform/UTF8, animation/key count, remote MCP requests. Potential outcomes: decompression bombs, XML entities/XXE, symlink escape, arbitrary script, memory/VRAM exhaustion, stale preview source, persistence corruption, style injection/content spoofing and exfiltration. Defenses proposed: DATA-01 VFS scoped grants/no-follow, DATA-03 parser quotas and non-executable import, DATA-02 asset provenance, versioned schema/canonical hash, bounded CPU/heap/atlas limits, path normalization, preview-only and explicit apply authorization, per-owner CAS/journal, redaction. Plugins not trusted or installed by a document.

**Known investigation gaps:** exact Qt module obligations and system linking model, currently changing Spine license (verify at adoption date), LDtk importer license/asset rights, Unicode distribution notices, GPU/multiplatform/IME/AT-SPI evidence, no reproducible actual performance number. License review is not legal advice. No benchmark or accessibility conformance has run.

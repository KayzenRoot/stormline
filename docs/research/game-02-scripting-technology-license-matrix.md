## Proposed recommendation and evidence gates
1. **First hypothesis:** Luau for gameplay user scripts, only through a Stormline-owned capability-scoped host binding and validated compiler/source/bytecode provenance; test isolation and hostile C++ callbacks. Lua 5.4 is a same-API reference comparator. Decide after real minimum slice and sandbox tests, not by benchmark marketing.
2. **One semantic API, two authoring paths:** typed visual graph backed by shared `ScriptApiSchemaV1`/IR and capability grants, not a second privileged VM. First graph slice intentionally small and must demonstrate parity (command outcomes, auth, replay, error mapping) with textual source.
3. **WASM only after need:** Wasmtime/WAMR/Wasm3 compare at least interp/no-JIT, memory limits, fuel/interrupt, host call validation, startup/compile cost, native/Web availability and content provenance. Do not add a second runtime to an MVP automatically.
4. **Security/risk:** Lua/Luau VM sandbox is necessary but insufficient; malicious host callbacks, use-after-free entity bindings, untrusted bytecode, unbounded compile, unbounded logging, WASI imports and privileged editor/AI execution all require explicit typed denial and fuzz. Hostile multi-tenant scripts or privileged irreversible actions require separate HIGH_ASSURANCE, independent proofs and rollback.
5. **Determinism:** command commit order and replayable TickId inputs can be deterministic; GC, runtime optimizations, floating-point rounding, threaded tasks, OS clocks, WASI randomness and Web native differences are not automatically bitwise equal. Record source/ABI/compiler/seed/epoch hashes and compare semantic receipts, not universal bitwise claims.
6. **Editor/CLI/MCP:** same authenticated schema staging/diagnostics/preview/CAS/hot reload contracts; no arbitrary eval/shell/direct filesystem/network or bypass of GAME/WORLD authority. UI graph library is not a gameplay runtime.
7. **Licenses and assets:** verify each exact tag, license and notices, transitive dependencies/SDK, Luau attribution, user-project script ownership/provenance, generated bytecode derivation and target distribution. No library or sample script copied, installed or run as part of this P00.
8. **No numerical claims:** full benchmark/test plan exists, but no native/Web/headless VM binary, performance, fuzz, sanitizer, memory, benchmark or legal packaging proof has been executed.
